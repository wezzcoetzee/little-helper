# little-helper design

Approved direction: B, Compact toolbox. True black background, white primary text, system sans typography, fixed 420 × 600px popup, fine dividers, small original monochrome l-plus icon. Keep the header, search, tabs and footer stable across pages; scroll the tool list inside the popup. Tabs: This site, Browser, All tools. Single-line action labels with short right-aligned details. Long hostnames truncate without squeezing the brand. No decorative cards or pills. Search filters tools. A matching side panel provides Markdown capture and editing. Native form controls, visible focus, and concise feedback.
